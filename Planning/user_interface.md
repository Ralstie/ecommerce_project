## Home Page

The home page will contain:

- Website name/logo
- Navigation bar
- Search bar
- Featured products
- Available stores
- Login/Register buttons
- Footer

## Product Page

The product page will display:

- Product image
- Product name
- Store name
- Product description
- Price
- Available stock
- Add to Cart button

## Shopping Cart

The shopping cart will display:

- Product name
- Product price
- Quantity
- Item total
- Cart total
- Remove button
- Checkout button

## Vendor Dashboard

The vendor dashboard will display:

- Vendor information
- Vendor stores
- Store management buttons
- Product management buttons

## Buyer Dashboard

The buyer dashboard will display:

- Buyer information
- Orders
- Previous purchases
- Reviews
