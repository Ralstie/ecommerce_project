# E-Commerce Marketplace

This project is a Django-based e-commerce marketplace developed as part of my practical tasks.

## Features

- User registration
- Buyer and vendor roles
- Vendor dashboard
- Store creation
- Product creation
- Product listings
- Product details
- Shopping cart
- Checkout
- Orders
- Product reviews
- Login and logout
- Password reset

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap

## How to Run the Project

1. Clone the repository.
2. Create a virtual environment.
3. Activate the virtual environment.
4. Install the required packages.
5. Configure the MySQL database.
6. Run Django migrations.
7. Start the development server.

Example:

```bash
python manage.py migrate
python manage.py runserver
